# Einsatzlyzer 10.6.13

## Deutsch

- Sehr kurze Einsätze bis 100 m Luftlinie vom Feuerwehrhaus erzeugen keine ungültige OSRM-Route mehr. Einsatzlyzer speichert dafür eine transparente lokale Näherung.
- Routing-Fehler in der Stapelverarbeitung enthalten jetzt Einsatztitel und einen direkten Link zum jeweiligen WordPress-Einsatzeditor.
- Weiterführende Links besitzen zusätzlich zur URL eine Quellangabe, z. B. „Feuerwehr Uplengen“ oder „Presseportal“.
- Die Quellangabe wird im Frontend dargestellt und automatisch in vollständigen Sicherungen exportiert und wiederhergestellt.
- Deutsche und englische Oberfläche wurden für die neuen Felder und Meldungen ergänzt.

## English

- Incidents within 100 m straight-line distance of the fire station no longer produce invalid OSRM routes. Einsatzlyzer stores a transparent local approximation for these very short distances.
- Batch routing errors now include the incident title and a direct link to the corresponding WordPress incident editor.
- Further links now include a separate source field, for example “Uplengen Fire Department” or “Press portal”.
- Link sources are displayed in the frontend and are automatically included in complete backup and restore.
- German and English interface text has been updated for the new fields and messages.
