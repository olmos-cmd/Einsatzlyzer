# Einsatzlyzer 10.6.4

## Deutsch

Diese Fehlerkorrektur behebt die Weiterleitung zur normalen Beitragsübersicht beim Hochladen einer Einsatzdepesche aus einem bereits geöffneten Einsatz. Ursache waren verschachtelte HTML-Formulare im WordPress-Beitragseditor. Der Upload, die Vorschau sowie Übernehmen und Abbrechen verwenden nun technisch getrennte Formulare. Die aktuelle Einsatz-ID bleibt erhalten.

## English

This maintenance release fixes the redirect to the regular posts list when uploading a dispatch PDF from an already open incident. The cause was nested HTML forms inside the WordPress post editor. Upload, preview, apply and cancel now use technically separate forms and preserve the current incident ID.
