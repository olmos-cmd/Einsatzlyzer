# Einsatzlyzer 10.4.2

## English

Version 10.4.2 adds automatic batch retrieval for historical weather data. The weather administration page can now process all suitable incident reports without requiring one button click per report.

### New
- Fetch missing weather data automatically.
- Refresh all weather data.
- Retry only failed requests.
- Progress bar with processed, successful and failed counts.
- Pause, resume and stop controls.
- Persistent per-incident error marker for targeted retries.
- Sequential AJAX processing to avoid server timeouts.

## Deutsch

Version 10.4.2 ergänzt den automatischen Stapelabruf historischer Wetterdaten. Auf der Wetterseite können jetzt alle geeigneten Einsatzberichte verarbeitet werden, ohne jeden Bericht einzeln anklicken zu müssen.

### Neu
- Fehlende Wetterdaten automatisch abrufen.
- Alle Wetterdaten neu abrufen.
- Nur fehlgeschlagene Abrufe erneut versuchen.
- Fortschrittsbalken mit bearbeiteten, erfolgreichen und fehlgeschlagenen Einsätzen.
- Pause-, Fortsetzen- und Beenden-Funktion.
- Dauerhafter Fehlerstatus pro Einsatz für gezielte Wiederholungen.
- Serielle AJAX-Verarbeitung zum Schutz vor Server-Timeouts.
