# Einsatzlyzer 10.5.4

## English

This release fixes annual-report exports that could fail without visible feedback. PDF, CSV and XLSX are now generated as protected files in the WordPress uploads directory. After creation, the administrator receives a secure download button. Errors such as missing ZipArchive, missing write permissions, empty years or failed file creation are shown directly. A browser print view provides an additional PDF fallback.

## Deutsch

Diese Version behebt Jahresbericht-Exporte, die bisher ohne sichtbare Rückmeldung scheitern konnten. PDF, CSV und XLSX werden nun als geschützte Dateien im WordPress-Upload-Verzeichnis erzeugt. Anschließend erhält der Administrator einen sicheren Download-Button. Fehler wie fehlendes ZipArchive, fehlende Schreibrechte, leere Jahre oder eine fehlgeschlagene Dateierstellung werden direkt angezeigt. Zusätzlich steht eine Browser-Druckansicht als PDF-Rückfallebene zur Verfügung.
