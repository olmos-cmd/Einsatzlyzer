# Einsatzlyzer 10.1.1

## English

This maintenance release rebuilds the mobile WordPress incident overview for a cleaner and more reliable layout.

- no horizontal page overflow
- readable two-column overview cards
- compact heading, logo and create button
- search field and search button in separate full-width rows
- stable filter layout without pagination overlap
- pagination moved to a dedicated centered row
- compact incident cards with readable titles
- smaller touch-friendly actions instead of oversized buttons
- empty and unrelated cache actions removed on mobile
- desktop layout and stored incident data remain unchanged

## Deutsch

Dieses Wartungsupdate baut die mobile WordPress-Einsatzübersicht sauber neu auf.

- keine horizontale Verschiebung der Seite mehr
- vollständig lesbare Übersichtskarten in zwei Spalten
- kompaktere Überschrift, kleineres Logo und passender Erstellen-Button
- Suchfeld und Suchschaltfläche jeweils über die volle Breite
- stabiles Filterlayout ohne Überlagerung mit der Seitennavigation
- Seitennavigation in einer eigenen zentrierten Zeile
- kompakte Einsatzkarten mit vollständig lesbaren Titeln
- kleinere touchfreundliche Aktionen statt übergroßer Schaltflächen
- leere und fremde Cache-Aktionen werden mobil entfernt
- Desktop-Darstellung und gespeicherte Einsatzdaten bleiben unverändert
