# Einsatzlyzer 10.5.1

## Deutsch
Diese Version macht den historischen Wetterabruf vollständig standortunabhängig. Gültige Koordinaten der Einsatzstelle haben immer Vorrang. Fehlen sie, verwendet Einsatzlyzer den in den Einstellungen hinterlegten Feuerwehrhaus- oder Standardstandort. Die Quelle wird gespeichert und im Backend angezeigt. Lokale Jümme-/A28-Sonderlogik ist nicht mehr enthalten.

## English
This release makes historical weather retrieval location-independent. Valid incident coordinates always take priority. If they are missing, Einsatzlyzer uses the configured fire-station or default location. The source is stored and displayed in the backend. Local Jümme/A28-specific logic has been removed.
