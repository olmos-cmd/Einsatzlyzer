# Einsatzlyzer 10.5.0

## Deutsch
Diese Version automatisiert die Ortszuordnung für historische Wetterdaten im Einsatzgebiet Jümme. A28/BAB-Varianten und Straßenklassen werden normalisiert. Fehlende Koordinaten werden aus dem Einsatzort ermittelt, geprüft und gespeichert. Unplausible Wetterwerte oder Positionen außerhalb der Region werden nicht übernommen.

## English
This release adds automatic location resolution for historical weather data in the Jümme response area, road-name normalization, bounded geocoding and plausibility validation.
