# Einsatzlyzer 10.4.7

## English

- Adds the existing Einsatzlyzer icon to the installed WordPress plugins list.
- Updates the plugin description to present the current feature set: historical weather, incident timeline, maps, galleries, SEO and complete import/export.
- Uses only the existing local branding asset.

## Deutsch

- Zeigt das vorhandene Einsatzlyzer-Symbol in der WordPress-Liste der installierten Plugins an.
- Aktualisiert die Plugin-Beschreibung auf den aktuellen Funktionsumfang: historisches Wetter, Einsatzzeitachse, Karten, Galerien, SEO sowie vollständiger Import und Export.
- Verwendet ausschließlich die bereits vorhandene lokale Branding-Datei.
