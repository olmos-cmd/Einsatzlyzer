# Einsatzlyzer 10.4.4

Version 10.4.4 redesigns the historical-weather administration page for mobile devices. The narrow five-column table is replaced by full-width incident cards below 783 pixels, while the desktop table remains unchanged.

## English
- Mobile card layout for historical weather.
- Separate fields for incident, alert time, coordinates and weather.
- Full-width fetch or refresh button.
- Responsive batch controls and progress display.

## Deutsch
- Mobile Kartenansicht für historische Wetterdaten.
- Getrennte Bereiche für Einsatz, Alarmierungszeit, Koordinaten und Wetter.
- Breiter Button zum Abrufen oder Aktualisieren.
- Responsive Stapelsteuerung und Fortschrittsanzeige.
