# Einsatzlyzer 10.6.15

## Deutsch

- Einsatzarchiv SEO-freundlicher und kompakter gestaltet.
- Archivüberschrift ist jetzt immer eine H1 und kann unter **Einsatzlyzer → Einstellungen** frei geändert werden, z. B. „Feuerwehr Einsätze Lammertsfehn“.
- Kurze Archiveinleitung für 2–3 Sätze vorgesehen.
- Optionaler längerer SEO-Zusatztext kann unterhalb der Einsatzliste angezeigt und jederzeit abgeschaltet werden.
- Automatische ALT-Texte für Archivbild, Einzelansicht und Galerie aus dem Einsatznamen ergänzt.
- Bei mehreren Bildern erhält das erste Bild den Einsatznamen; weitere Bilder erhalten „Einsatzname – Bild 2“, „Einsatzname – Bild 3“ usw.
- Manuell in der WordPress-Mediathek gesetzte ALT-Texte werden niemals überschrieben.
- Neue Archiv-Einstellungen werden wie alle `ffl_`-Optionen in vollständigen ZIP-Sicherungen mitgesichert.

## English

- Improved the incident archive for SEO while keeping the header compact.
- The archive heading is now always an H1 and can be customized under **Einsatzlyzer → Settings**.
- The short archive introduction is intended for 2–3 concise sentences.
- An optional longer SEO text can be displayed below the incident list and disabled at any time.
- Added automatic ALT text for archive images, the single incident view and gallery images based on the incident title.
- For multiple images, the first image uses the incident title; subsequent images use “Incident title – Image 2”, “Incident title – Image 3”, etc.
- Manually entered WordPress media ALT text is always preserved.
- The new archive settings are included automatically in complete ZIP backups with the other `ffl_` options.
