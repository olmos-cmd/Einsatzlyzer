# Einsatzlyzer 10.4.5

## Deutsch
Diese Version macht den vollständigen Export und Import verlustfrei. Gesichert und wiederhergestellt werden sämtliche Einsatz-Metafelder, Wetterdaten, Zeitachsen, Kurz- und Langberichte, Bilder, Bildmetadaten, Kommentare, verwandte Einsätze, Ausschlusslisten, Taxonomien und alle dauerhaften Einsatzlyzer-Einstellungen. Verknüpfungen werden über stabile UUIDs wiederhergestellt.

## English
This release provides lossless full backup and restore for all incident fields, weather data, timelines, reports, images and metadata, comments, related incident relationships, taxonomies and persistent Einsatzlyzer settings.
