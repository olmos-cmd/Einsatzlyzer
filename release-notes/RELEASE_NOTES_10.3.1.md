# Einsatzlyzer 10.3.1

## English

- Completed schema integrations for Yoast SEO, Rank Math, All in One SEO and SEOPress.
- Centralized `NewsArticle` and breadcrumb normalization and removed remaining `Event` nodes.
- Added a cached live schema inspection for rendered incident pages.
- Expanded the incident list with separate Content, Image, Schema and Indexing status columns.
- Added checks for publication status, `noindex`, canonical URL, permalink and preview image size.
- Made the diagnostics and cache workflow fully bilingual.
- Improved diagnostic performance with pagination and cached live checks.
- Cache notices now remain visible until caches are cleared or explicitly confirmed.
- Clarified that an nginx server does not prove that nginx caching is enabled.
- Added compatibility and regression test documentation.

## Deutsch

- Schema-Anbindungen für Yoast SEO, Rank Math, All in One SEO und SEOPress vervollständigt.
- `NewsArticle` und Breadcrumbs zentral vereinheitlicht und verbleibende `Event`-Knoten entfernt.
- Zwischengespeicherte Live-Schema-Prüfung für ausgegebene Einsatzseiten ergänzt.
- Einsatzübersicht um getrennte Spalten für Inhalt, Bild, Schema und Indexierung erweitert.
- Prüfungen für Veröffentlichungsstatus, `noindex`, Canonical-URL, Permalink und Bildgröße ergänzt.
- Diagnose- und Cache-Ablauf vollständig zweisprachig ausgeführt.
- Diagnose durch Seitennavigation und zwischengespeicherte Live-Prüfungen beschleunigt.
- Cache-Hinweis bleibt sichtbar, bis das Leeren bestätigt oder ausgeführt wurde.
- nginx-Erkennung korrekt formuliert: Ein nginx-Server beweist keinen aktiven nginx-Cache.
- Kompatibilitäts- und Regressionstest-Dokumentation ergänzt.
