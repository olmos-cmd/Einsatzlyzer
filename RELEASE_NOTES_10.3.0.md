# Einsatzlyzer 10.3.0 – Release Notes

## English

Version 10.3.0 focuses on reliable structured data, transparent diagnostics and faster SEO quality control.

- Active SEO plugins now remain the single source for schema output, preventing duplicate Article and BreadcrumbList nodes.
- Yoast Event nodes and nested Event data are removed from incident reports.
- A new diagnostics page shows the detected SEO provider, cache systems, schema responsibility, default-image dimensions and the overall incident SEO status.
- Incident editing now includes an SEO and image check.
- The incident overview contains a compact SEO status column.
- Cache systems are detected where possible, and a cache-clearing reminder appears after updates.
- Supported WordPress caches can be cleared directly; nginx, hosting and CDN caches remain clearly identified as external.
- User-created incident data and uploaded images are not modified.

## Deutsch

Version 10.3.0 konzentriert sich auf zuverlässige strukturierte Daten, nachvollziehbare Diagnose und eine schnelle SEO-Qualitätskontrolle.

- Aktive SEO-Plugins bleiben jetzt die einzige Quelle für Schema-Ausgaben. Doppelte Article- und BreadcrumbList-Knoten werden vermieden.
- Yoast-Event-Knoten und eingebettete Event-Daten werden bei Einsatzberichten entfernt.
- Eine neue Diagnose-Seite zeigt erkannten SEO-Anbieter, Cache-Systeme, Schema-Verantwortung, Standardbild-Abmessungen und den SEO-Gesamtstatus der Einsätze.
- Auf „Einsatz bearbeiten“ steht eine SEO- und Bildprüfung zur Verfügung.
- „Alle Einsätze“ enthält eine kompakte SEO-Statusspalte.
- Cache-Systeme werden soweit möglich erkannt; nach Updates erscheint ein Hinweis zum Cache-Leeren.
- Unterstützte WordPress-Caches lassen sich direkt leeren. nginx-, Hoster- und CDN-Caches werden als externe Caches klar benannt.
- Selbst eingegebene Einsatzdaten und hochgeladene Bilder werden nicht verändert.
