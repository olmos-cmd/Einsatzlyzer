# Einsatzlyzer 10.4.3

## English

Version 10.4.3 improves the mobile incident page layout. The incident image section now follows the historical weather block directly, uses a single compact heading, and places the image count beside the heading. This reduces unnecessary scrolling without changing images or report content.

## Deutsch

Version 10.4.3 verbessert die mobile Darstellung der Einsatzseite. Der Bereich „Einsatzbilder“ schließt jetzt direkt an den historischen Wetterblock an, verwendet nur noch eine kompakte Überschrift und zeigt die Bildanzahl rechts daneben. Dadurch wird unnötiges Scrollen reduziert, ohne Bilder oder Einsatzinhalte zu verändern.
