# Einsatzlyzer 10.6.14

## Deutsch

- Die Quellangaben der fünf weiterführenden Links sind jetzt ausdrücklich Bestandteil des vollständigen Sicherungsvertrags.
- URL und Quellangabe werden als zusammengehörige Felder im ZIP-Backup gesichert und beim Import wiederhergestellt.
- Sicherungsschema auf Version 7 erhöht; ältere Sicherungen bleiben importierbar.
- Automatischer Regressionstest für alle zehn Link-/Quellenfelder ergänzt.

## English

- Source labels for all five external reference links are now explicitly part of the complete backup contract.
- Each URL and its source label are backed up together and restored during import.
- Backup schema raised to version 7; older backups remain importable.
- Added an automated regression test covering all ten URL/source fields.
